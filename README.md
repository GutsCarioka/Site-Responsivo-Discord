# Descritivo do projeto
  Esse Site alem de utilizado para treinamento de Estruturação em HTML e Css Tambem foi focado em Responsividade e no metodo Mobile First.  
  Utilizando boas práticas de tags semânticas. Além de validação com ferramentas como o WAVEvolution e DevTols do Google.
  Esse trabalho me ajudou a consolidar um estilo de programação voltado para código limpo, acessível e escalável.
